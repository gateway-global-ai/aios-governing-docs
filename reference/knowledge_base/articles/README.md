# Knowledge Base Articles

This folder contains long-form knowledge artifacts intended for agent retrieval and human review.

## Categories

| Category | Purpose |
|------|---------|
| `Case Study Addenda` | Follow-on analyses that isolate a narrower mechanism, escalation path, or newly observed surface inside an existing case-study record. |
| `Case Studies` | Empirical incident analyses that anchor thesis claims in concrete system behavior, observed failure surfaces, and architectural prescriptions. |
| `Research Studies` | Structured evidence syntheses derived from source reports, organized into chapters, key findings, and visual diagrams. |
| Concept articles | High-level explanatory artifacts that define a concept or framework without acting as runtime authority by themselves. |
