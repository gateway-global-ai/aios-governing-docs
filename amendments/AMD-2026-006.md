# Amendment: Google Workspace Governed Integration Plane

## 1. Rationale

Google Workspace MCP servers expose a broad tool surface (mail, drive, calendar, docs, automation). Exposing that surface directly to conversational or voice layers creates **unbounded execution risk**.

**Normative bulk:** This amendment **ratifies** **[AIOS-SPEC-007](../specifications/GoogleWorkspaceIntegrationGovernance.md)** **v1.0.0** (`ratified`) as the binding **technical** contract for Workspace integration: **Intent Layer → Workspace Intent Router → Integration Control Plane → MCP Adapter → Google APIs**, with **Layer 1** governance scope classes and **Layer 2** operational intents (**one intent → exactly one scope class**), policy packs **POL-WORKSPACE-001–006** where applicable, phased rollout, and audit requirements described in that specification and cross-referenced standards.

Round 1 peer review (**[REVIEW_SYNTHESIS](../reviews/amd_2026_006/round_1/REVIEW_SYNTHESIS.md)**) **FAILED** on **[AMD-2026-005](AMD-2026-005.md)** numerics primarily because the **amendment body was a stub** relative to **SPEC-007**. **v0.2.0** addresses that by **pointing** to strengthened **SPEC-007** text (**§§5–8**, **Annex A**) rather than duplicating normative tables inline.

## 2. Proposed Changes

### Change 1: Ratify AIOS-SPEC-007 (ratified **v1.0.0**)

**Affected document:** [AIOS-SPEC-007](../specifications/GoogleWorkspaceIntegrationGovernance.md)  
**Effect:**

- **Ratified:** **AIOS-SPEC-007 v1.0.0** is the **authoritative** Workspace integration specification for products claiming compliance, superseding **v0.1.x** for **normative** requirements in **§§2–8** and **Annex A** (informative paths).
- **Google Workspace integration** **MUST** comply with **§2** (routing chain), **§5** (routing envelope), **§6** (control plane outcomes), **§7** (canvas / **SPEC-006** alignment), **§8** (**SPEC-010** execution scope), and **§3** (web retrieval / PSE) where applicable.

### Change 2: Extend AIOS-SPEC-003

**Affected document:** [AIOS Agent Integration Protocol](../specifications/AgentIntegrationProtocol.md) (**AIOS-SPEC-003**)  
**Effect:** Assistants **MUST** emit governed **`workspace.\*`** intents per **AIOS-SPEC-007**; **MUST NOT** invoke MCP tools directly from the agent layer by ad hoc tool names.

### Change 3: Extend AIOS-SPEC-006

**Affected document:** [UI Component Registry Standard](../specifications/UIComponentRegistryStandard.md) (**AIOS-SPEC-006**)  
**Effect:** Workspace **canvas** surfaces (**`workspace_hub`**, service hubs, onboarding) **SHALL** be registered per **AIOS-SPEC-007 §7** and **AIOS-SPEC-006** (footer, load states, exit contracts).
