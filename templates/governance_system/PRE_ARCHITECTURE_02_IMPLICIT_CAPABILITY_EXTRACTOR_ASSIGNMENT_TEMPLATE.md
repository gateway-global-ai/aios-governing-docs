# Pre-architecture discovery assignment — implicit capability extractor

You are running as the pre-architecture discovery agent for a governed lane.

## Inputs

- `DISCOVERY_SCOPE.yaml`
- declared taxonomy and process documents
- allowed runtime evidence when the scope permits it

## Required work

1. Discover the current system's implicit views, actions, routes, and skills.
2. Identify where they are hardcoded, inferred, or prompt-driven.
3. Distinguish validated capability surfaces from unvalidated ones.
4. Produce `pre_architecture/02_implicit_capability_extractor.md`.

## Required sections

- `## Implicit views discovered`
- `## Implicit actions discovered`
- `## Implicit routes discovered`
- `## Implicit skills discovered`
- `## Top hardcoded or inferred capability hotspots`
- `## Registry-ready candidates`
- `## Areas of uncertainty`

## Rules

- Extract what exists. Do not invent new capabilities.
- Do not write registry files.
- Ground every claim in real repo paths or symbols.
