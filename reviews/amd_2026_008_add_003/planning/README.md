### Troubleshooting

| Error | Action |
|-------|--------|
| **`ConnectError` / `10061` / connection refused** | Start **Ollama** on this machine (`ollama serve` or the Windows app). Ensure **`OLLAMA_MODEL`** is pulled (e.g. `ollama pull llama3.2`). Re-run the **architect** command. |
| **Timeout / OOM** | Default KB bundle is **~260k** chars — local models may struggle. Pass a **smaller** `--bundle` path (custom excerpt) or increase patience; consider a machine with more RAM. |
| **Dry run** | `py -3 scripts/ollama_planning_agent.py --role architect --amd-slug amd_2026_008_add_003 --dry-run` — prints prompt sizes only. |
