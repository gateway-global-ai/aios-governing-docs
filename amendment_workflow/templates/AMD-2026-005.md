## Summary

- **Workspace model:** Hub (`amendment_hub`) → selection → workflow (`amendment_workflow`); no implicit run creation on entry.  
- **Intents:** `governance.amendment.hub` | `.resume` | `.review` | `.create` (legacy `.workflow` → hub).  
- **Transparency:** Resource loads use `ok` | `empty` | `error`; never treat API failure as empty registry.  
- **Governance:** Supersedes post–peer-review human audit requirement in non-constitutional guides; ratification path = author pre-validation → triangulated PR → thresholds → constitutional ratification.  
- **Failure policy:** No silent fallback to conversational mode when governed intent cannot resolve—explicit disambiguation or policy denial.
